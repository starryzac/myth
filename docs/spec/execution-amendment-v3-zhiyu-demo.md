## 冻结范围

- 四页：总览、我的规则、目标与执行、活动记录。
- 两条实际离线语法：`保留3000元应急金`；`旅行目标1.2万元，截止2027-06-30，每月固定储备1000元。`。组合句不被完整理解时如实拒绝，标注“规则解析演示”。不新增 LLM 供应商。
- 单目标：既有 `single-goal-allocation-v1` 预览及 `/actions` 执行器。服务端选择真实目标账户；收入使用确认后到达的固定 200000 分银行事实。金额/来源由原引擎计算。
- 三场景：A 确认规则并安全执行；B 撤销后准备被拒绝且无经济效果；C 独立银行实际提交后丢失响应，保留 UNKNOWN，再按同一 action_id 恢复。
- A 与 C 是同一月额度的两种执行方式，使用新的隔离轮次分别演示；不制造额外月额度。两次完整演示均覆盖三场景，记录实际轮次及命令。
- Demo 使用独立 `bf_test_<32hex>` 数据库、专属数据库角色和 API/Web 进程。保留兼容模拟用户 UUID，但用户数据属于新的独立数据库命名空间。标准库与已有演示实例不重置。
- 精确路由白名单默认封闭高级 API；原完整入口保留。浏览器切换前检查旧未决 locator，拒绝覆盖或删除未知状态。
