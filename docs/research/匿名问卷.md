状态：**NOT_STARTED**。下面没有预填参与者答案或研究分数。所有问题可以选择“不知道/不愿回答”；缺失不按错误或0分填充。记录仅用随机参与者代码、条件A/B/C与任务ID。

## 每任务后

1. 您认为该任务是否完成？完成 / 部分完成 / 未完成 / 不知道 / 不愿回答。请简述您依据哪个界面信息判断。
2. 您能否说明本次配置或动作的金额、来源、去向/目标归属、可用时点及具体权限？请用自己的话说；不知道的部分请指出。主持人不补写答案。
3. 您有多大把握以上解释正确？0–100，或不知道/不愿回答。信心不是正确性或系统安全概率。
4. 哪些地方需要您确认或回答？哪些提示重复、难懂或令人反感？自由文本可留空；不要填写真实个人或银行信息。

任务解释由独立评分人按冻结任务卡和真实原件核对；金额/权限来源缺失则评分为MISSING，不推定参与者理解错误或系统成功。评分记录必须含实际评分人代码、时刻和依据，原回答不覆盖。
