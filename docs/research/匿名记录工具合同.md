# 最小匿名记录/导出合同（候选）

实际协议：`bounded-funds-adult-simulated-study-v1`。状态：**LOCAL_TOOL_READY / STUDY_NOT_STARTED**。`scripts/research_records.py` 已实现最小入口/导出，32直接风险测试仅合成TOOL_ONLY；三条件真实人类界面、参与者、数据和效果尚未验证。此合同不添加金融权限或研究结果。

## 范围

实现为单一本地CLI：`init` 创建全新目录，`append` 录入四种明确原输入，`export` 输出全新匿名JSON/任务CSV。没有网络、招募/通知或真实账户导入；不会连接正式库、改金融历史或启动资金动作。CLI退出0只说明记录/文件操作完成，不代表任务成功、真人已见或研究效果。

实际最小注册显式提供study_id随机UUID4、原同意材料文件及保存截止日，工具原字节保存`consent.original.md`并重核hash。三条件/六任务固定完整登记。当前工具不验证伦理批准、负责人是否真实、三条件界面或参与者是否确实在场，因此这些研究前置仍由主持人按README逐项核验；不能凭CLI同意字段造实际同意或称正式研究就绪。

## 匿名与导出

不收集身份映射表、真实账号、密码、签名cookie/Bearer或联系方式。字段采用允许清单；自由文本的自动模式检查只提供提示，不能声称全面脱敏，导出前必须人工复核实际文本。疑似个人数据保持隔离/阻断公开，不自动删除所有反馈来伪造干净结果。

私有原始文件与公开CSV/JSON分开。公开导出剔除撤回码、精确操作时间和可能识别人的自由描述；保留条件、任务分母、缺失/退出与匿名分数。导出人需显式确认已复核哪些记录，留下实际清单，不自动认证真人同意或研究结论。没有实际records时只输出空数据与NOT_STARTED，不创建示例参与者混入正式文件。

## 实际闭合输入

各输入同时必需 `kind`、随机UUID4 `event_key`、匿名随机UUID4 `participant_id`。未知字段（姓名/联系方式/账号/role/success等）拒绝，重复JSON键和NaN拒绝。单原输入1MiB显式上限；不把超限/非有限值变成null。`CONSENT` 以外都须唯一原成年自报+明确同意，撤回后不能追加；同event_key只能重放完全相同原输入。

| kind | 其余精确字段 |
|---|---|
| CONSENT | adult_self_reported=true、explicit_consent=true、quote_consent bool、consent_document_sha256、consented_at aware ISO、condition_order（A/B/C各一次） |
| TASK_OBSERVATION | condition A/B/C、task_id R01–R06、status COMPLETED/PARTIAL/ABANDONED/NOT_RUN/UNSUPPORTED/INTERRUPTED、measurement_source RESEARCHER_RECORDED/PARTICIPANT_SELF_REPORTED、started_at/ended_at null或aware ISO、duration_seconds null或非负有限数、intervention_count/researcher_help_count null或0–10000严格整数、supersedes_event_id null或该任务最新原event_id |
| QUESTIONNAIRE | condition、measurement_source、control_answers（完整C1–C6，各null或1–7严格整数）、conceptual_answers（完整K1–K6，各null或YES/NO/UNKNOWN/SKIPPED）、confidence_percent null或0–100严格整数、feedback_text null或至多2000字符、feedback_privacy_reviewed显式bool、supersedes_event_id null或该条件最新问卷原event_id |
| WITHDRAWAL | withdrawal_token（首次同意原私有回执的随机token） |

时间/时长与评分来源仅人工记录或参与者自报，工具不将其称为软件测得。记录使用append-only原输入/回执顺序hash以检测意外改写，不是金融typed审计、外部签名、伦理批准或真人真实性证明。修正保留旧body并精确引用最新原件。并发append以本地独占锁阻挡，残留锁不自动删除他进程记录。撤回后默认导出排除该参与者全部记录；原私有记录未物理删除，输出`withdrawal_raw_records_deleted=false`，实际删除需数据管理人员另处理，不能声称已删除。

匿名JSON/CSV对每位未撤回、持有同意记录者固定保留3×6任务；未观测为MISSING_NOT_RECORDED，时长/计数为null。只有原观察status才显示完成，没有自动评分、优势比较、显著性或研究结论。空目录导出NOT_STARTED/0记录，非空仅OPERATOR_RECORDS_PRESENT_NOT_HUMAN_VERIFIED。

默认自由文本不导出；`--include-reviewed-text` 还要求该问卷原人工复核声明为true且参与者原quote_consent=true。该声明不自动认证匿名性。邮箱、11–19连续数字、带明确标注的姓名/账号/秘密等有限PII模式拒绝；无法保证识别所有自然文本中的个人信息，正式采集/公开前仍需人工审查。私有撤回token、原同意正文、精确任务起止时间不进入匿名导出。
