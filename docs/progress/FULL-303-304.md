## 可运行能力和原来源

新增 `POST /api/v1/goal-reallocation/preview`，请求只允许 `policy_id`、`source_goal_id`、`expected_policy_version_id`、`expected_goal_policy_version_id`、`expected_epoch_id` 五个身份字段；正文和 query 未知字段拒绝。时钟和用户来自原服务依赖。Root 负责注册 router 和将本 POST 设置为同请求 RR / READ ONLY，未接共享注册前不能声称主应用入口已可用。

服务在同一实际只读快照中读取当前 OPEN epoch、原 Goal、已验真 FullPolicy 不可变版本/命令链与当前 Evidence、原 `full_reconciliation` 独立模拟银行账本、原 FullAnnual 的当前 `BEFORE_PAYMENT` 保护点及完整在途 reservation 分母。仅所有者、业务时点、银行 cash、全部 Goal cash/principal、审计和来源均可核时输出数学值。无跨请求授权缓存，不写 action、Evidence、confirmation、银行、收入或历史哈希。

数学范围是当前原硬义务、生活准备金、应急底线三项。未归属且未预占现金为实际银行现金减原锁定目标现金及已核预占；三个按固定顺序的前缀缺口之和是这个已登记当前范围的唯一最小修复额。源 Goal 可释放上限取现金和超最低保障部分的较小值，保留本金资产放置及其他 Goal 归属；未来收入和本金释放均为零。在途资源归属不能排除重复扣除时数学状态为 UNKNOWN，所有相关金额为 null，不能把重复扣除造成的更大金额称为最低修复。

数学值与金融候选分离：默认关闭、非列明目标、条件不符、撤销/暂停、日期不符、单笔或已核累计上限不足为 BLOCKED；无紧急缺口为 NO_EMERGENCY；其余缺少原专用 grant 或累计使用原件时为 UNKNOWN。`candidate_amount_cents` 恒为 null，`bank_authority=false`、`financial_grant_created=false`、`repairs_performed=false`、`execution_support=NOT_IMPLEMENTED`。已有规划确认不能授予银行权限。原 `canonical_goal_bridge` 的 cross=true 拒绝负例保留。
