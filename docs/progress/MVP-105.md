实现决策：相同原文、日期基准、编译版本和引擎可重复；原文及完整解析持久保存，修订用原 compilation_id，跨日不重解“明年”。缺金额、日期或限制时保留 draft/issues，不创建可确认候选；用户编辑完整结构后必须查看并通过原有摘要确认。明确建议额不会升级为硬最低额，含糊锁期不变成资产授权。原编译记录不被用户修订覆盖。

语法边界：采用有限子句全匹配，支持中文完整数词、精确小数、中文或 ISO 日期、今年/明年、固定月额和明确范围。计划黄金句中的“明年十月前”按严格排他解释成 2027-09-30，原计划 DSL 示例为 2027-10-01；此处公开该解释并要求复核，不把两者描述为同一天。黄金句缺少 min/max 和量化锁期，因此只生成草稿。否定、条件、未知子句、非法/过期日期、歧义金额和矛盾范围不静默删掉；后端使用整数分和 Decimal，尚不声称前端大整数展示已实现。

持久化：输入摘要和完整 CompilationResult 摘要同时绑定来源标识，保存并发安全的原编译结果；编辑另建证据和候选修订。来源、模型结果或完整编译输出同 ID 被改写后，即使更新当前内容摘要，也不能直接确认旧候选。属于本协议的一层绑定，数据库管理员同时改写所有独立字段不在其防护声明内。
