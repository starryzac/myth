# 初版威胁、控制与实证边界

状态：W1 WORKING_DRAFT，2026-10-05。本文件登记当前控制和具体实证范围；没有将初版/完整版安全验收标为完成。正式旧模拟库保持只读，全部资金测试进入生成隔离库；禁止LibreOffice。

## 保护对象与可信边界

保护用户确认、不可变策略版本、账户/目标/收入源分归属、原动作效果、独立银行请求与posting、回执、事实来源和审计原件。银行事实、用户意图与授权分开；自然语言/模型输出属于候选。页面只能请求原身份及明确确认，不能提交权限级别、成功状态、账本余额或私有模拟时钟。
