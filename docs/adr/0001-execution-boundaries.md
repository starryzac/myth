# ADR 0001：实施与验证边界

日期：2026-10-03（Asia/Shanghai）

- 按 MVP-001 至 MVP-504、FULL-001 至 FULL-907 的计划顺序推进。未通过阶段门不进入下一阶段。
- 计划原文位于仓库根；当前实现以钱途有界两计划为准，不沿用其他旧选题的功能范围。
- 全部账户、产品、动作都是合成模拟；没有真实银行凭据或资金通道。
- 当前明确的测试接缝来自用户授权的两计划：HTTP API、确定性引擎公开函数、策略生命周期、执行/回执、审计验证和浏览器用户流程。按照每任务红绿测试逐步实现。
- 金额为整数分；数据库 PostgreSQL 16，时间 UTC。不会以 SQLite 替代 PostgreSQL 验收。
- Windows 使用同一 Python 任务入口的 make.cmd；GNU Make 通过 Makefile 调用同一入口，保持命令语义一致。
- M0 检验当前已实现健康闭环；后续增加真实检查，未实现检查明确失败，不能空实现返回成功。
- 不使用 LibreOffice。未执行用户研究、实验或运行验证不得标为完成。
