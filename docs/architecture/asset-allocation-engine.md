# 单产品资产配置引擎

公开纯函数：`select_asset(snapshot, boundary_versions, positions, boundary_products, authorization, products, exposure, *, source_issues=())`。所有金额为严格整数分，无外部调用、无数据库写入。实现选择见 [ADR0007](../adr/0007-single-product-allocation.md)，本文件不替代最终验收证据。

## 输入及证据边界

入口重新验证快照、授权、曝光和产品 DTO，不能用 Pydantic model_copy 绕过严格金额/时间类型；202引擎继续重验其完整金融输入。最多100产品/1000来源问题，产品UUID与(code,version)均唯一。曝光引用不能重复、交叠或指向未知持仓；所选scope的现有未结清本金必须分类为明确人工持仓或已计入自动本金，自动本金合计必须与managed_principal一致。来源不足时没有精确推荐。

曝光epoch可以早于查询as_of，但不得早于采用的账户余额水位或晚于查询。服务另外验证完整金融/执行事实水位、银行证明、历史授权和目标归属epoch，纯函数不会自行授予来源真实性。

## 一般资金与目标资金

一般范围仅使用CASH账户中扣除各目标归属的现金，资金来源按账户UUID稳定分配。所有范围的一般待申购预留先视为整窗不可用，得到reservation_adjusted_boundary；这样既有现金和未执行预留不能同时用于新候选。目标预留已包含在目标现金保护中，不再作为一般预留双扣，只减少该目标可配置上限。

目标范围校验当前目标策略及asset_policy_id，使用该目标已有cash_owned。候选x将所选账户余额与本目标cash_owned各减x、同目标principal_owned加x；allocated/month contribution不变，其他目标和未映射目标现金保持。临时持仓保留goal_id，返本后同目标现金保护同步增加。

## 有限候选

每product_code选择已知且当前有效的最高版本；保留旧版本/未来版本的拒绝原因，不把缺条款默认成安全。风险、自动买入、锁定/赎回时延、明确百分之百无损本金、零费计息协议、起投和当前授权逐项过滤。缺省kind可由protocol推导，显式kind必须与protocol一致。

一般比较90日；目标到款日最迟为本地deadline前一日。固定产品只持有一个明确term，不续作；T0/T1从比较窗扣结算等待得到计划请求日，再按当前资产授权失效时点提前。日计算使用as_of加整数自然日；请求严格早于授权失效。本金到账与收益计息共享计划，结算等待和提前回款后的现金不计收益。

对每个可用产品，构造现金购买和反事实本金返回后态，整数二分查找全部273检查点均安全的最大金额，再与单笔和剩余管理额度相交。最大额仍需符合起投；重新计算被选金额的完整边界。购买当下也校验，不因T0允许立即赎回而跳过购买检查。

净模拟收益为 `amount * annual_bps * earning_days // 3650000`，只在乘积最后截整一次。最多选择一个正收益产品，零收益保留现金。并列依次比较无损流动性天数、赎回时延、product_code/version/UUID；余款保持现金。不是所有退出日、再投资路径或多产品组合的全局优化。

## 返回及确定性

输出基线、预留调整和选中后态边界，逐产品原因、最大额度、退出计划和整数收益，所选产品、来源账户用量和保留现金。源数据、授权、规范曝光、产品和候选共同绑定selection_hash；无序身份清单、输入账户/目标/策略/产品重排不应改变结果。展示收益变化只影响排名/selection_hash，不增加现金或本金边界。

READY/financial_only/preview_only不是执行许可。当前接口不会预留额度；并发预览可相互竞争，MVP-301须在提交前重新验证并原子记账。UNKNOWN/不可唯一对账继续关闭新购，恢复与自主等级在205/302处理。

## 验证边界

额度中断后root接管并修复已保存的8项严格输入/排序失败，随后补充“未分类既有本金不得释放额度”的真实red→green。35项纯域测试通过，来源/HTTP合并40项通过；独立性质和全项目最终质量门以MVP-204进度文件及真实日志为准。源码没有修改202核心算法或203目标贡献语义。
