# MVP-204 独立资产配置账本

依据 [ADR 0007](../adr/0007-single-product-allocation.md)，只验证一个当前授权范围、每个产品一个确定退出方案的有限候选集，不声称遍历全部退出日期或完整产品组合。测试文件为 [test_asset_allocation_properties.py](../../apps/api/app/tests/test_asset_allocation_properties.py)。公开纯函数接口和独立手算模型已完成定向验证；整体质量门另行记录。

## 独立预期

小整数账本逐分枚举候选 x，按 90 日的付款前、付款后和本金到账后检查点，分别记录现金、所选目标现金、其他目标现金及一个已确认保护金额变更。它不调用生产 `compute_boundary`、规划器或其私有函数生成 expected。

一般范围买入时现金减 x，保护不变；目标范围买入时现金和该目标现金同时减 x，同目标本金加 x，allocated 与本月贡献不变。本金到账后逆转这组变化。其他目标和未归属目标现金不得被借用。该简化账本不实现第二套完整日历、债务、证据或银行记账引擎。

退出方案先独立固定：定期只取一个合同 term；T0/T1 在比较窗末前扣结算等待日提出请求，授权若更早到期则退到仍有效的最后一个整数日。请求/到期前计息，结算等待及提前回款后的剩余比较窗不计息。收益用 `本金分 × 年化bps × 实际计息日 // 3650000` 一次向下取整，永不加入现金安全本金。

## 字面真值

本金 1000000 分，T0=150bps、T1=180bps/等待1日、固定30日=220bps/无续作：

| 比较窗 | T0收益分 | T1收益分 | 固定收益分 | 应选择 |
| --- | ---: | ---: | ---: | --- |
| 90日 | 3698 | 4389 | 1808 | T1 |
| 5日 | 205 | 197 | 不合格 | T0 |
| 6日 | 246 | 246 | 不合格 | T0（流动性并列优先） |
| 7日 | 287 | 295 | 不合格 | T1 |

授权在 day3 零点失效时，按整数日请求的 T0/T1 最迟 day2 请求，收益分别 82/98 分；固定合同30日到期不需要未来主动请求，仍为1808分。本金100分、5日窗时两者收益均0，应保留现金。生产产品起投金额另行校验，小整数 oracle 可使用1分起投。

两条独立安全反例：

- C=100、其他保护20、所选目标已有现金80：general cap=0；goal范围可把80现金转成同目标本金，前后margin均0。
- C=100、day2起保护100：按明确持有90日退出的 T0，cap=0。错误地让本金day0返回会得到cap100，但这种退出只能计0日收益，不能再计90日。
